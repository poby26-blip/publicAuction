# Public Auction (공공경매/공매 안드로이드 앱)

안드로이드 기반의 공공경매(Public Auction) 모바일 애플리케이션 프로젝트입니다.  
화면 설계는 Google Stitch를 기반으로 진행하며, Kotlin 및 Jetpack Compose를 활용하여 구현합니다.

## 프로젝트 정보
- **플랫폼**: Android
- **개발 언어**: Kotlin
- **UI 프레임워크**: Jetpack Compose
- **화면 설계**: Google Stitch
- **버전 관리**: Git & GitHub
