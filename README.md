# 공매이지 (Public Auction 모바일 앱)

공공데이터 포털 및 한국자산관리공사(KAMCO) 온비드 기반의 공매 정보 탐색 모바일 하이브리드 애플리케이션 **'공매이지'** 프로젝트입니다.  
화면 기획 및 디자인은 **Google Stitch**를 기반으로 하며, 프론트엔드는 **React + TypeScript + Vite + Tailwind CSS**를 사용하여 구현합니다.

## 프로젝트 구조
```text
publicAuction/
├── frontend/          # React 기반 웹 프론트엔드 (모바일 하이브리드 UI)
├── .gitignore         # 프로젝트 공통 Git 제외 설정
└── README.md          # 프로젝트 문서
```

## 기술 스택 (Frontend)
- **프레임워크**: React (with Vite)
- **언어**: TypeScript
- **화면 설계**: Google Stitch
- **버전 관리**: Git & GitHub

## 개발 안내
`frontend/` 디렉터리 내에서 웹 프론트엔드 개발 및 빌드가 진행됩니다.
